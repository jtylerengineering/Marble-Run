## Description
This is my submission for Week 2 of Half Life. As indicated by the title, it is a 3d printed marble run. My design is meant to be modular. It will receive some updates after Half Life (hopefully), but that will be a project for future me whenever he's bored.

**Note:  Example design will be posted by week 7. I am just posting the system for week 2. I am still trying to figure out the assembly tool and need time to figure out how to configure an example.**

### Features
This system includes:
- Baseplates to allow for expansion of run
- collumn segments to adjust height
- a few different slide sections to combine and even edit in OnShape (make a copy).
- A module for a wheel-based lifter system

## Requirements
In order to make the components as is, you will need:
1. a 3d printer
2. filament (I'm using PLA here)
3. Onshape (if you want to edit compenents)
4. A slicer that is compatible with your printer (I used Bambu Studio)

## Tips
- If you want to plan out your build a bit, use OnShape's assembly function to build out the overall layout of your design.
- For curved slides, use the 'Sweep' tool.
